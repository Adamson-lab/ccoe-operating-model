# Maturity Model and Roadmap

Diagram: [10 Roadmap and gates](../diagrams/svg/10-cloud-adoption-roadmap-maturity-gates.svg).

| Level | Name | Evidence |
|---|---|---|
| L1 | Ad hoc | Individual heroics, no common standards |
| L2 | Repeatable | Landing zone and charter exist |
| L3 | Defined | Guardrails as code, ADRs, catalogue |
| L4 | Managed | KPIs reviewed monthly, auto-remediation |
| L5 | Optimising | Data-driven standards, multi-cloud parity |

Each wave exits through a measurable gate (see diagram); a wave is not declared complete until the gate is evidenced on the scorecard.
