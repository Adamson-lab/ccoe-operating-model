# CCoE Charter

## Mission
Make the secure, compliant and cost-efficient way to use cloud the easiest way, for every product team.

## Scope
Cloud strategy and standards, landing zones, guardrails, shared platform services, FinOps, and cloud skills across AWS, Azure and GCP.

## Out of scope
Application design decisions owned by product teams; workload-specific runbooks; non-cloud infrastructure.

## Principles
1. **Paved road over policing.** Make the compliant path the default and fastest.
2. **Everything as code.** Policy, decisions, ownership and metrics live in Git and change by pull request.
3. **Federated ownership.** Central core owns the platform; BU champions own adoption (ADR-0007).
4. **Time-boxed deviation.** Exceptions are visible, temporary and compensated (ADR-0008).
5. **Measure outcomes.** The KPI scorecard is reviewed monthly; red KPIs get an owner and a plan.

## Authority and decision rights
See [RACI](03-raci.md). The Cloud Council approves charter changes; the ARB decides standards through ADRs; the Exception Board decides waivers.

## Funding
Core team is centrally funded; consumption is allocated by product via showback, moving to chargeback in Wave 2.

## Review
The charter is reviewed annually, or after any Sev-1 cloud security incident.
