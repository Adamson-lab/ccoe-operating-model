# FinOps Practice

Diagram: [12 FinOps loop and pipeline](../diagrams/svg/12-finops-operating-loop-cost-allocation-pipeline.svg).

- **Allocation:** four mandatory tags (G-TAG-001) plus account-to-product mapping; shared costs split by rules in the allocation engine.
- **Optimisation order:** rightsize, remove waste, commit on steady state (target 70% coverage), spot for fault-tolerant work, then modernise.
- **Budgets:** alert at 80%, escalate to CCoE at 100%, throttle sandbox on breach.
- **Cadence:** weekly showback, monthly FinOps Board, quarterly commitment review.
